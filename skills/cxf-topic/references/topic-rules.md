# 出题规则

## 一条选题长什么样

- **类型**：流量款 / 信任款 / 转化款，见 SKILL.md。
- **题干**：一句话，观众视角，说清这条讲什么、观众能得到什么。是一件可拍的事、一个可教的做法、一个没见过的画面，不是空壳（「如何成为……」「十大技巧」），也不是写好的爆款标题。
- **观众为什么点**：一句，说中一种动机：利益（省时间、省钱、多赚钱）、好奇（没见过、反常识）、新鲜（刚出的东西）、焦虑（怕落后、怕被坑）、认同（说出了他想说的）。
- **你凭什么讲**：档案里的成绩、经历、技能，写编号或小节。
- **星级**：流量、客资各 1～5 星。
- **来源**：热点（日期 + 链接）/ 观众需求 / 他的打法。

## 三个池子怎么攒

### 观众需求池

站在第③节那群人的位置问：

- 他们最想要什么结果？（多一份收入、省掉重复的活、做出好看的东西）
- 他们最怕什么？（花冤枉钱、被坑、走弯路、错过机会）
- 他们卡在哪一步？（不知道用什么工具、不知道第一步做什么、做了没人看）
- 他们会搜什么、会问朋友什么、会把什么转给朋友？

第③节写的人群太窄时（比如「想开奶茶店的人」），往外扩一圈想：更大的人群（所有爱喝奶茶的人、所有想开小店的人）会不会也想看？会，就按大人群写题干，流量款尤其要这样。

### 热点池

- 按他的行业和观众查，不按别人的行业查。做装修的查装修，做律师的查法律，做 AI 的才查 AI。
- 只用近 2 天（今天和昨天）、查得到来源的。超过 2 天的不用。
- 两类都看：行业热点（新政策新规、价格变化、新产品、行业事件、刷屏案例、季节节点）和大众热点（热搜上和他的行业或观众挂得上钩的事）。挂不上就不用。
- 每条热点翻成观众角度，四种翻法：
  - 「这件事对你有什么影响」：新规、涨价、新产品，落到观众自己的钱、时间、风险上；
  - 「你现在该怎么办」：给一个能照着做的动作；
  - 「我干这行的怎么看」：用他的经验说出外行看不到的一层；
  - 「我实测了 / 我做给你看」：他亲手试一遍，讲结果和坑。
- 不要只转述新闻，那谁都能发。

### 他的打法池

档案第④节里，他做爆过、做成过的方法（M 编号、S 编号里的做法）。打法比故事更值钱：故事讲一次就用完了，打法能套到每一个新热点上。

## 改写示例

下面的例子只说明怎么改，行业和事实都是举例，出题时以用户档案和真实查到的热点为准。

| 原来的题（不好） | 问题 | 改成 |
|---|---|---|
| 我做装修 8 年，最难忘的一个工地 | 主角是博主自己，观众得不到东西 | 信任款：装了 8 年房，我最怕业主在这一步省钱（前提：档案里有这段经历） |
| 律师行业为什么越来越卷 | 圈内话题，外行不关心 | 流量款：离婚时房子写谁名字，这三种情况结果完全不一样 |
| 我们店的新品上市了 | 硬广，没收获 | 转化款：开奶茶店前，先算清这三笔账，不然半年就关门（前提：他真开过店或带过加盟） |
| 某地出台了新的租房政策 | 纯转述新闻 | 流量款：新的租房规定下个月生效，租客现在就该做的两件事 |
| 我做 AI 自媒体 11 个月只顾接商单 | 主角是博主自己 | 信任款：同一条新闻，念稿和自己做一个演示，播放能差几百倍：我把那条拆给你（前提：他真做爆过） |

## 排序

1. 先排除：禁区、讨厌、否掉过、与方向无关、五关过不了的。
2. 按配比留够流量款、信任款、转化款。
3. 同类型里：流量星高的排前；转化款看客资星。
4. 有真实成绩撑着的 > 只有观点的；有画面的 > 纯说理的。

## 少于 5 条时

照实交。末尾写还差什么，例如：

- 「再补 1 个你带别人做出结果的例子，转化款能更硬」
- 「这次没查到热点，联网后再出，能多 2 条流量款」

不要用鸡汤和空壳清单凑数。

## 换一批

新题干与上一批明显不同；仍过五关；仍最多 5 条。档案没变、也没新热点时，换角度和人群，不要假装有新调研。
