# 模式说明

开口前先判断模式。一次对话可以换模式，比如首次建库途中用户发来一篇文章，就转成导入材料，读完再接着问缺口。

## 1. 首次建库

**什么时候**：用户说「帮我建资料库」「让AI了解我」「做个人档案」，当前没有【我的档案】，也没给材料。

**开场**（一段话说完，不要长）：

> 我会像聊天一样问你几个问题，一次只问一个，照实说就行。每题我都会给一个猜测，对的话回「是」就好。不想说的说「跳过」，觉得够了说「够了」。提醒一句：聊的内容会经过 AI 模型处理，不放心的部分只讲公开版就行。

**流程**：入口4问 → 走 A/B/C 一条路 → 第8问左右总结和3条选题样例 → 用户选继续深挖或收尾 → 分段复述确认 → 写出档案 → 验收。

**交付**：【我的档案】v1，版本行写「v1｜日期｜本次：首次建立」。

**中途停下**：用户说「先到这」，就把已确认的内容先写成档案，没确认的进「待确认清单」，在「采访进度」里写清走的哪条路、问到哪、下一题准备问什么。

## 2. 导入材料（高手通道）

**什么时候**：用户一上来就发了个人简介、公司介绍、写过的文章、账号主页截图、后台数据，或者一大段自述。

**做法**：

1. 先读完全部材料，不要边读边问。
2. 从材料里抽取能确定的内容，按档案的8节填一份草稿。材料能证明的标[事实]并写来源（如「来源：用户发的公司介绍」）；用户原句标[原话]；你归纳的标[推测]。
3. 入口4问里，材料已经能回答的，改成确认句：「从你的简介看，你是做企业培训的，主要客户是制造业老板，对吗？」
4. 列出缺口，只追问缺口。缺口按影响排序：想讲给谁听 > 能讲的故事 > 观点 > 出镜方式和说话风格 > 选题偏好。
5. 有账号数据的创作者：请用户发「数据最好的3条和最差的3条」，再问「你觉得好的那条好在哪」。

**注意**：材料里的夸张说法（如官网写的「行业领先」）不能照搬，按 `privacy-and-truth.md` 的禁用词处理；材料里的客户名、电话、地址不入库。

**交付**：先交草稿 + 缺口清单，用户确认后写成【我的档案】。

## 3. 更新档案

**什么时候**：用户说「更新我的档案」「我最近换方向了」「这条不对」，或者崔先锋选题交回采纳、否掉的原因。

**做法**：按 `update-and-review.md` 的「更新模式」列改动清单（新增/修改/删除），用户确认后写入，版本号+1。

**交付**：新版【我的档案】和一份改动清单。

## 4. 体检复核

**什么时候**：用户说「检查我的档案」「档案还准吗」，或档案里有节超过3个月没确认。

**做法**：按 `update-and-review.md` 的「体检复核」出体检结果，再问用户要复核哪几条，一次复核一条。

**交付**：体检结果；用户复核后，走更新模式出新版。

## 5. 验收

**什么时候**：刚写完档案，或用户说「验收」「测一下档案好不好用」。

**做法**：只看档案，回答3–4个验收问题（见 `update-and-review.md`），每个答案注明依据编号。答不准、拿不出依据的地方当场补问一题。

**交付**：验收结果（通过，或还需补问的地方）和补进档案的内容。

## 6. 继续采访

**什么时候**：用户说「继续采访」「接着上次问」。

**做法**：先读【我的档案】的「采访进度」和「待确认清单」，用一句话说「上次聊到……，这次从……接着问」，然后按进度里记的下一题开始。没有找到档案时，请用户把档案发来，或从首次建库开始。
