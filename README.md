# 崔先锋 CXF Skill

![version](https://img.shields.io/badge/version-1.4.0-blue) ![license](https://img.shields.io/badge/license-MIT-green) ![agent-skills](https://img.shields.io/badge/agent--skills-中文-orange)

**让 AI 认识你，再帮你做自媒体。** 崔先锋 CXF 是一套中文 Agent Skill，作者：崔先锋。国内外支持 Skill 的 Agent 都能用（WorkBuddy、Claude Code、Codex 等），档案可存进腾讯 ima 或本地。

关键词：AI自媒体、自媒体选题、口播稿、文案检查、防限流、个人知识库、资料库、内容抓取、WorkBuddy、ima。

## 七个板块

| 板块 | 做什么 | 状态 |
|---|---|---|
| 崔先锋资料库 cxf-library | 聊几句天，让 AI 认识你，整理成一份【我的档案】 | ✅ 已发布 |
| 崔先锋选题 cxf-topic | 每天给你出有流量、能带客户的选题：查热点 + 读你的资料库，每条标类型和星级 | ✅ 已发布 |
| 崔先锋写稿 cxf-script | 把挑中的选题写成你能直接念的完整口播稿，另附 2 个备选开头和画面建议 | ✅ 已发布 |
| 崔先锋检查 cxf-check | 发布前查稿：四项分开查：AI 味、防限流、逻辑连贯、看不懂 | ✅ 已发布 |
| 崔先锋防限流 cxf-safe | AI 自媒体专用：发布前换掉软件名、Logo、导流；被限流了一步步抢救 | ✅ 已发布 |
| 崔先锋复盘 cxf-review | 发布后要截图、记数据，存进「数据复盘」文件夹，越用越懂你 | ✅ 已发布 |
| 崔先锋抓取 cxf-fetch | 抓链接、对标账号、热点内容 | ✅ 已发布 |

另有总入口 `cxf`：不知道从哪开始，就说「崔先锋能帮我做什么」，它会介绍各个板块，并把你的话交给对的板块。

资料库是底，只建一次。之后每天走一遍：选题 → 写稿 → 检查，发出两三天后再复盘。每一步做完，它会问你要不要接着下一步，你回一个编号或「要」就行。

## 怎么安装

**方式一：命令行安装**（支持 `npx skills` 的 Agent）

```bash
npx skills add cuixianfeng/cxf-skill
```

会装上本仓库里的全部 Skill（`cxf`、`cxf-library`、`cxf-topic`、`cxf-script`、`cxf-check`、`cxf-safe`、`cxf-review` 和 `cxf-fetch`）。

**方式二：手动安装**

把仓库里 `skills/` 下的 `cxf`、`cxf-library`、`cxf-topic`、`cxf-script`、`cxf-check`、`cxf-safe`、`cxf-review`、`cxf-fetch` 文件夹，整个复制到你所用 Agent 的 skills 目录下。只想要资料库，复制 `cxf-library` 一个也能用；只要选题，复制 `cxf-topic`（出题会读【我的档案】，建议同时保留 `cxf-library`）；写稿 `cxf-script` 同样读【我的档案】；检查 `cxf-check`、防限流 `cxf-safe`、复盘 `cxf-review` 单独就能用；只要抓取，复制 `cxf-fetch` 即可。

**方式三：WorkBuddy 用户**

在 WorkBuddy 对话框里直接说：

> 帮我安装这个 Skill：https://github.com/cuixianfeng/cxf-skill

**没装 Skill 也想试试？** 打开 [docs/prompt-lite.md](docs/prompt-lite.md)，把里面的提问词复制粘贴给 AI 就能用（资料库精简版）。

# 崔先锋资料库 cxf-library

**聊几句天，AI 就认识你了。** 崔先锋资料库像朋友一样一次问你一个问题，把你真实的经历、观点和边界整理成一份【我的档案】，存进腾讯 ima 或本地。以后 AI 给你出自媒体选题、帮你做事，都先读这份档案。

## 适合谁

- 想做 AI 自媒体，但不知道自己能讲什么的人。
- 刚开始用 WorkBuddy 等 AI 智能体、不懂技术的人。不用装数据库，不用懂 MCP、API。
- 在自己行业里很强的人：老板、销售、律师、会计、老师……AI 会按你手里的牌换问法，你是行家，它就问得更深、更准。

一句话：小白有收获，高手有高天花板。

## 怎么用

装好后，对 AI 说一句：

- 「帮我建资料库」：从头开始采访
- 「更新我的档案」：加新信息、改不对的地方
- 「检查我的档案」：看哪些过期了、哪些还没确认
- 「继续采访」：接着上次问
- 直接发简介、文章、账号数据：AI 先读材料，只问缺的

## 效果示例

> 以下对话均为**虚构示例**，人物和数字都是编的。

**素人（示例：物流公司行政）**

> **AI**：问这个是因为别人反复找你的事，往往就是你没发现的本事：同事最常因为什么事来找你？推荐答案：帮忙填报销、订会议室这种？
> **用户**：新人入职清单吧，好多人来问我要。
> **AI**：一份清单被好多人要，说明它真管用。最近一次有人来要，是什么时候、怎么回事？
> **用户**：上个月来了个新人，第一天没打卡被扣钱……后来人事也拿去用了。
> **AI**：（第8问左右）按你的真实经历，先给3条选题样例：①入职第一天没打卡被扣钱？这份清单我做了3年行政才整理出来（依据：S01）……

**老板（示例：社区烘焙店，12家）**

> **AI**：问这个是因为目的不同，选题完全不同：做内容你最想换来什么？推荐答案：我猜是多来客人，对吗？
> **用户**：其实不是，客人不缺，缺店长。
> **AI**：那内容的目的要转向招人。从第1家到第12家，最难的是哪一家？
> **用户**：第5家，选址失败，半年就关了。
> **AI**：那次之后，选址上你改了什么？……这条属于你的生意门道，我记成「仅内部」，建议别放进选题会读的库。

同样一套 Skill，对素人像聊家常，对老板像顾问。

## 产出什么

一篇 Markdown 文档，标题固定为【我的档案】，第一行写版本号，比如「v1｜2026-11-03｜本次：首次建立」。分8节：

1. 我是谁
2. 想做的方向（每个方向都写「凭什么讲」和「什么情况说明它不成立」）
3. 想讲给谁听
4. 能讲的故事和观点（编号 S01、O01，原话保留）
5. 产品与服务（有才写）
6. 出镜方式、平时怎么说话、不碰的话题
7. 选题偏好：喜欢什么、否掉过什么
8. 给 AI 的使用须知、采访进度、待确认清单

每条信息都标 [原话] [事实] [推测] [待确认]，AI 不会把猜的当成事实写进文案。

存法：在 ima 里新建一个知识库（比如叫「崔先锋资料库」），把这篇存进去。用崔先锋选题时可以勾选这个库，也可以直接说「帮我选题」，它会自己找到这篇。更新后，同一个库里只留最新版。

## 设计原则

- **一次只问一个问题**，每题说明为什么问，附推荐答案，回「是」就行。
- **不给人分等级**：AI 用得不熟，不代表你在自己行业不熟。按你手里有什么牌换口吻。
- **只问发生过的事**：多问「最近一次是什么时候」，不问「你想成为什么样」。
- **先给甜头**：第8问左右就给你3条基于真实经历的选题样例。
- **没依据的不写**：每个方向都要有真实依据和不成立条件；不用「专家」「大师」「赋能」这类词夸你。
- **你确认了才写**：分段复述，逐条确认；更新只追加，不覆盖旧内容。
- **随时可停**：说「跳过」就不再问，说「够了」就收尾。

## 隐私说明

- 采访内容会经过你所用的 AI 模型处理。生意上不放心的，只讲公开版就行。
- 身份证、电话、住址、银行卡、精确收入营收、客户真名、病史、孩子姓名学校、合同细节，一律不入档案。
- 太具体的会被模糊化，比如营收写「千万级」，城市只写到省；讲客户、员工、家人的故事会去掉身份信息。
- 本仓库的 Skill 不上传你的文件到任何第三方，不读取密钥、密码，档案存在你自己选的地方。
- 示例中的人物和数据全部为虚构。

# 崔先锋选题 cxf-topic

**从你的目标观众想要什么出发，一次给你最多 5 条有流量、能带来客户、你今天就能拍的选题。** 能联网时先按你的行业和观众查近 2 天的热点（行业新规、价格变化、行业事件，以及和你挂得上钩的热搜），再把你做爆过的打法套上去；你的档案用来证明「你凭什么讲」。每条标流量款、信任款或转化款，写清观众为什么会点、你凭什么讲、流量和客资各几颗星。不写标题、封面和文案。

## 怎么用

装好后，对 AI 说一句：

- 「用 CXF 选题 Skill」
- 「请用 CXF 选题 Skill 帮我做选题」
- 「帮我选题」
- 「今天拍什么」
- 「给我几个题」「出选题」

说口令即可。它会自动找标题为【我的档案】的那一篇：当前对话里贴过的、你勾选或关联的知识库、或你刚才点名的库。

有一个大致方向就能出题，不必档案八节全齐。方向太糊时，最多反问一句；你跳过或答不上，也照样出题，并标明方向待你改。唯一会停下来的情况：找不到档案，而且你这句话里完全没有方向——这时会请你先用崔先锋资料库建一份，或先说一句大致方向。

一次最多交 5 条。每条都要过五关：不认识你的人刷到会不会停下、看完能带走什么、你凭什么讲、外行能不能看懂、主角是不是观众而不是你自己。有产品或打算做的产品（比如付费社群）时，配成 3 条流量款 + 1 条信任款 + 1 条转化款；没有就 4 条流量款 + 1 条信任款。热点只用查得到来源的，查不到就写「这次没查热点」，不编。

交完会问你挑哪条。回编号，就直接交给崔先锋写稿写成口播稿。

# 崔先锋写稿 cxf-script

**把挑中的选题，写成你能直接念的完整口播稿。** 只用【我的档案】里的真事和原话，照你平时说话的样子写。先按选题类型定时长和结构，料不够先问你关键细节，再把选题答应的过程和方法讲透。

## 怎么用

- 崔先锋选题交完题后，直接回编号，比如「2」
- 或者说「用 CXF 写稿 Skill，把这个题写成口播稿：……」

## 你会拿到什么

- 一篇完整口播稿，按选题类型定长度：拆解复盘、教程方法约 2 分钟（450～600 字），观点、故事约 1 分半（350～450 字）；说了时长就按时长写
- 开头 15 秒讲清话题、给一个钩子、说明为什么信你；中间每一步讲到能照着做
- 每条稿子都有三个亮点：一个认知差、一个能看见的画面、一两句能截图的话
- 一句推进思路，2 个打法不同的备选开头（每个写清从哪句接回正文），2～4 条画面建议
- 用到的依据编号；缺关键细节时，写清还差什么、补上能写多长

写之前，档案里缺关键细节（某一步具体怎么做的、结果多少），它会先问你，一次一个，最多 3 个。不编经历、数字和结果。档案里没有真料时，它会先请你讲一次真实经历。这是初稿，念一遍，把不像你的句子告诉它，它只改那一句。不写标题封面，不承诺流量。

# 崔先锋检查 cxf-check

**发布前把稿子分四项查一遍，每项单独列问题和改法。**

- **AI 味**：「不是……而是……」翻案腔、「一句话总结：」这类宣告、空开头、套话、鸡汤收尾、没出处的「研究表明」
- **防限流**：绝对化用词、承诺收益、医疗功效、加微信等导流（谐音缩写也算）、诱导互动、反复喊软件名、AI 生成内容没声明
- **逻辑连贯**：跳步、前后打架、因果硬接、开头不兑现、绕圈、结尾跑题
- **看不懂**：站在你的目标观众位置听：术语缩写没解释、「这个」「它」指代不清、数字没参照、句子太长、离了画面听不懂

每处标「必须改」或「建议改」，给原句、问题和能直接念的改法。每项最多 3 处，没问题就写「没发现问题」。

## 怎么用

- 崔先锋写稿交稿后，回「要」
- 或者说「用 CXF 检查 Skill，检查这篇稿子」，再贴上稿子（自己写的也行）

稿子没问题就直接说能发。只改说法，不改你的观点、故事和数字，不加编的细节。风险词只提示「可能有风险」，不保证过审。

# 崔先锋防限流 cxf-safe（AI 自媒体专用）

**讲 AI 工具、智能体、软件教程的博主专用。** 这类视频最容易因为露出具体软件名、Logo、网址和导流被平台抽检限流。

## 怎么用

- 发之前：「用 CXF 防限流 Skill，我要发小红书」，再贴上稿子、标题、标签。它按平台列出口播字幕要换的词、画面要打码的地方、标题和标签改法、封面提醒。
- 发之后：「是不是被限流了？发了 1 小时，播放 30，推荐页占比 0%」。它先判断是不是真限流，再告诉你下一步只改哪一处：先改文字，再换封面，最后才动视频本身。

平台松紧按博主实测经验：小红书最严，抖音中等，B 站、视频号、快手较松。这是经验，不是官方规则，不保证不限流。只处理软件名、Logo、导流这类露出问题，不帮违规内容绕过审核。

# 崔先锋复盘 cxf-review

**视频发出 48～72 小时后，把数据收回来，让 AI 越用越懂你。** 你说「复盘」，它会主动告诉你去后台哪一页截图，再问一句这条带来了几个客资，不用你自己记要发什么。

## 怎么用

- 「用 CXF 复盘 Skill，复盘这条」，或直接发来后台数据截图
- 它会告诉你截哪一页：抖音、小红书、视频号、B 站、YouTube 各给一条路径
- 读完先把数字列给你确认，确认后才写入

## 记哪些数据

播放量、开头留存（抖音 5 秒完播率等，后台显示哪个记哪个）、完播率、点赞、评论、转发，以及**客资数**（私信、加群、加微信合起来算）。截图里没有的项写「未填」，照样复盘。

## 存在哪

在存【我的档案】的知识库里新建一个「数据复盘」文件夹（本地就是档案旁边的 `数据复盘/`），**不写进档案本身**。里面三样：每条一份复盘记录（数据 + 复盘卡 + 稿子原文）、一张复盘汇总表、一份「规律」。

## 越用越懂你

- **不到 10 条**：只记录，每条出一张复盘卡：开头留没留住人、内容看没看完、有没有戳中人、带没带来客资，再给一条下次可以试的。
- **满 10 条**：第一次总结，结论都标「待验证」。
- **同一类有 3 条以上都对得上**：才写成「规律」。之后崔先锋选题和崔先锋写稿都会先读这份规律。

不预测播放量。唯有实践才能成为大师：你拍得越多、复盘越多，它写出的东西越像你、越有效。

# 崔先锋抓取 cxf-fetch

**发链接，或说调研某个博主，就把公开作品的数据和逐字稿抓下来。** 崔先锋抓取支持抖音、B站、YouTube；小红书和视频号走备选（本地文件转写）。只处理公开内容，仅供个人学习研究。

## 怎么用

装好后，对 AI 说一句，或直接丢链接：

- 「抓这个链接」+ 作品链接或分享文案
- 「调研这个博主近半年点赞最高的10条」+ 主页链接
- 「平台抓取」「对标账号」「转写成文案」
- 本地视频/音频文件：只做转写

默认近半年、按点赞、前 10 条；能从话里推断的参数不会再问。

## 依赖说明

- 需要 **Python 3.10+**。第一次在本 Skill 的 `scripts/` 目录执行 `pip install -r requirements.txt`，再跑 `python platform_top.py doctor` 自检。
- 浏览器：优先用本机已装的 **Chrome / Edge**；没有时再装 Playwright 的 Chromium。
- 语音识别模型（SenseVoice + 标点，约 **230 MB**）在第一次转写时自动下载。
- YouTube 单条等场景可能还需要 `yt-dlp`。

## 合规

只抓公开作品，用于个人学习研究。不转载、不二次分发原视频或文案、不商用。登录 cookie 只存在本机。一次只调研一个博主，不要并发狂跑。
