# 崔先锋 CXF Skill

![version](https://img.shields.io/badge/version-1.3.0-blue) ![license](https://img.shields.io/badge/license-MIT-green) ![agent-skills](https://img.shields.io/badge/agent--skills-中文-orange)

**让 AI 认识你，再帮你做自媒体。** 崔先锋 CXF 是一套中文 Agent Skill，作者：崔先锋。国内外支持 Skill 的 Agent 都能用（WorkBuddy、Claude Code、Codex 等），档案可存进腾讯 ima 或本地。

关键词：AI自媒体、自媒体选题、口播稿、文案检查、个人知识库、资料库、内容抓取、WorkBuddy、ima。

## 五个板块

| 板块 | 做什么 | 状态 |
|---|---|---|
| 先锋资料库 cxf-library | 聊几句天，让 AI 认识你，整理成一份【我的档案】 | ✅ 已发布 |
| 先锋选题 cxf-topic | 每天给你出选题，先读你的资料库，每条注明依据编号 | ✅ 已发布 |
| 先锋写稿 cxf-script | 把挑中的选题写成你能直接念的口播稿，另附 2 个备选开头 | ✅ 已发布 |
| 先锋检查 cxf-check | 发布前查稿：风险词、AI 味、顺不顺 | ✅ 已发布 |
| 先锋抓取 cxf-fetch | 抓链接、对标账号、热点内容 | ✅ 已发布 |

另有总入口 `cxf`：不知道从哪开始，就说「先锋能帮我做什么」，它会介绍各个板块，并把你的话交给对的板块。

资料库是底，只建一次。之后每天走一遍：选题 → 写稿 → 检查。每一步做完，它会问你要不要接着下一步，你回一个编号或「要」就行。

## 怎么安装

**方式一：命令行安装**（支持 `npx skills` 的 Agent）

```bash
npx skills add cuixianfeng/cxf-skill
```

会装上本仓库里的全部 Skill（`cxf`、`cxf-library`、`cxf-topic`、`cxf-script`、`cxf-check` 和 `cxf-fetch`）。

**方式二：手动安装**

把仓库里 `skills/` 下的 `cxf`、`cxf-library`、`cxf-topic`、`cxf-script`、`cxf-check`、`cxf-fetch` 文件夹，整个复制到你所用 Agent 的 skills 目录下。只想要资料库，复制 `cxf-library` 一个也能用；只要选题，复制 `cxf-topic`（出题会读【我的档案】，建议同时保留 `cxf-library`）；写稿 `cxf-script` 同样读【我的档案】；检查 `cxf-check` 单独就能用；只要抓取，复制 `cxf-fetch` 即可。

**方式三：WorkBuddy 用户**

在 WorkBuddy 对话框里直接说：

> 帮我安装这个 Skill：https://github.com/cuixianfeng/cxf-skill

**没装 Skill 也想试试？** 打开 [docs/prompt-lite.md](docs/prompt-lite.md)，把里面的提问词复制粘贴给 AI 就能用（资料库精简版）。

# 先锋资料库 cxf-library

**聊几句天，AI 就认识你了。** 先锋资料库像朋友一样一次问你一个问题，把你真实的经历、观点和边界整理成一份【我的档案】，存进腾讯 ima 或本地。以后 AI 给你出自媒体选题、帮你做事，都先读这份档案。

## 适合谁

- 想做 AI 自媒体，但不知道自己能讲什么的人。
- 刚开始用 WorkBuddy 等 AI 智能体、不懂技术的人。不用装数据库，不用懂 MCP、API。
- 在自己行业里很强的人：老板、销售、律师、会计、老师……AI 会按你手里的牌换问法，你是行家，它就问得更深、更准。

一句话：小白有收获，高手有高天花板。

## 怎么用

装好后，对 AI 说一句：

- 「帮我建资料库」：从头开始采访
- 「更新我的档案」：加新信息、改不对的地方
- 「检查我的档案」：看哪些过期了、哪些还没确认
- 「继续采访」：接着上次问
- 直接发简介、文章、账号数据：AI 先读材料，只问缺的

## 效果示例

> 以下对话均为**虚构示例**，人物和数字都是编的。

**素人（示例：物流公司行政）**

> **AI**：问这个是因为别人反复找你的事，往往就是你没发现的本事：同事最常因为什么事来找你？推荐答案：帮忙填报销、订会议室这种？
> **用户**：新人入职清单吧，好多人来问我要。
> **AI**：一份清单被好多人要，说明它真管用。最近一次有人来要，是什么时候、怎么回事？
> **用户**：上个月来了个新人，第一天没打卡被扣钱……后来人事也拿去用了。
> **AI**：（第8问左右）按你的真实经历，先给3条选题样例：①入职第一天没打卡被扣钱？这份清单我做了3年行政才整理出来（依据：S01）……

**老板（示例：社区烘焙店，12家）**

> **AI**：问这个是因为目的不同，选题完全不同：做内容你最想换来什么？推荐答案：我猜是多来客人，对吗？
> **用户**：其实不是，客人不缺，缺店长。
> **AI**：那内容的目的要转向招人。从第1家到第12家，最难的是哪一家？
> **用户**：第5家，选址失败，半年就关了。
> **AI**：那次之后，选址上你改了什么？……这条属于你的生意门道，我记成「仅内部」，建议别放进选题会读的库。

同样一套 Skill，对素人像聊家常，对老板像顾问。

## 产出什么

一篇 Markdown 文档，标题固定为【我的档案】，第一行写版本号，比如「v1｜2026-11-03｜本次：首次建立」。分8节：

1. 我是谁
2. 想做的方向（每个方向都写「凭什么讲」和「什么情况说明它不成立」）
3. 想讲给谁听
4. 能讲的故事和观点（编号 S01、O01，原话保留）
5. 产品与服务（有才写）
6. 出镜方式、平时怎么说话、不碰的话题
7. 选题偏好：喜欢什么、否掉过什么
8. 给 AI 的使用须知、采访进度、待确认清单

每条信息都标 [原话] [事实] [推测] [待确认]，AI 不会把猜的当成事实写进文案。

存法：在 ima 里新建一个知识库（比如叫「先锋资料库」），把这篇存进去。用先锋选题时可以勾选这个库，也可以直接说「帮我选题」，它会自己找到这篇。更新后，同一个库里只留最新版。

## 设计原则

- **一次只问一个问题**，每题说明为什么问，附推荐答案，回「是」就行。
- **不给人分等级**：AI 用得不熟，不代表你在自己行业不熟。按你手里有什么牌换口吻。
- **只问发生过的事**：多问「最近一次是什么时候」，不问「你想成为什么样」。
- **先给甜头**：第8问左右就给你3条基于真实经历的选题样例。
- **没依据的不写**：每个方向都要有真实依据和不成立条件；不用「专家」「大师」「赋能」这类词夸你。
- **你确认了才写**：分段复述，逐条确认；更新只追加，不覆盖旧内容。
- **随时可停**：说「跳过」就不再问，说「够了」就收尾。

## 隐私说明

- 采访内容会经过你所用的 AI 模型处理。生意上不放心的，只讲公开版就行。
- 身份证、电话、住址、银行卡、精确收入营收、客户真名、病史、孩子姓名学校、合同细节，一律不入档案。
- 太具体的会被模糊化，比如营收写「千万级」，城市只写到省；讲客户、员工、家人的故事会去掉身份信息。
- 本仓库的 Skill 不上传你的文件到任何第三方，不读取密钥、密码，档案存在你自己选的地方。
- 示例中的人物和数据全部为虚构。

# 先锋选题 cxf-topic

**读【我的档案】，一次给你最多 5 条现在就能拍的选题。** 每条写清题干、依据编号、一句为什么适合你。不写标题、封面和文案。

## 怎么用

装好后，对 AI 说一句：

- 「用 CXF 选题 Skill」
- 「请用 CXF 选题 Skill 帮我做选题」
- 「帮我选题」
- 「今天拍什么」
- 「给我几个题」「出选题」

说口令即可。它会自动找标题为【我的档案】的那一篇：当前对话里贴过的、你勾选或关联的知识库、或你刚才点名的库。

有一个大致方向就能出题，不必档案八节全齐。方向太糊时，最多反问一句；你跳过或答不上，也照样出题，并标明方向待你改。唯一会停下来的情况：找不到档案，而且你这句话里完全没有方向——这时会请你先用先锋资料库建一份，或先说一句大致方向。

一次最多交 5 条。材料太薄就少交几条，并说明补哪类信息，下次能出满 5。档案里有产品或服务时，优先能带来咨询、私信、了解产品的题（转化、引流）；没有产品时，优先容易引起共鸣、讨论、转发的题（流量）。默认不做行业调研。

交完会问你挑哪条。回编号，就直接交给先锋写稿写成口播稿。

# 先锋写稿 cxf-script

**把挑中的选题，写成你能直接念的口播稿。** 只用【我的档案】里的真事和原话，照你平时说话的样子写。正文之外再给 2 个备选开头，专门用来留住前 5 秒。

## 怎么用

- 先锋选题交完题后，直接回编号，比如「2」
- 或者说「用 CXF 写稿 Skill，把这个题写成口播稿：……」

## 你会拿到什么

- 一篇口播稿，默认约 1 分钟、250 字左右；说了时长就按时长写
- 2 个打法不同的备选开头（先说结果、先抛冲突、说反常的事、点名观众，挑两种），每个写清从哪句接回正文
- 用到的依据编号；缺关键细节时，写清还差哪一句

不编经历、数字和结果。档案里没有真料时，它会先请你讲一次真实经历。这是初稿，念一遍，把不像你的句子告诉它，它只改那一句。不写标题封面，不承诺流量。

# 先锋检查 cxf-check

**发布前把稿子查一遍。** 查三样：风险词（绝对化、承诺效果、往外引流等）、AI 味、念起来顺不顺。只挑最多 3 处必须改的，每处给能直接念的改法。

## 怎么用

- 先锋写稿交稿后，回「要」
- 或者说「用 CXF 检查 Skill，检查这篇稿子」，再贴上稿子（自己写的也行）

稿子没问题就直接说能发。只改说法，不改你的观点和故事。风险词只提示「可能有风险」，不保证过审。

# 先锋抓取 cxf-fetch

**发链接，或说调研某个博主，就把公开作品的数据和逐字稿抓下来。** 先锋抓取支持抖音、B站、YouTube；小红书和视频号走备选（本地文件转写）。只处理公开内容，仅供个人学习研究。

## 怎么用

装好后，对 AI 说一句，或直接丢链接：

- 「抓这个链接」+ 作品链接或分享文案
- 「调研这个博主近半年点赞最高的10条」+ 主页链接
- 「平台抓取」「对标账号」「转写成文案」
- 本地视频/音频文件：只做转写

默认近半年、按点赞、前 10 条；能从话里推断的参数不会再问。

## 依赖说明

- 需要 **Python 3.10+**。第一次在本 Skill 的 `scripts/` 目录执行 `pip install -r requirements.txt`，再跑 `python platform_top.py doctor` 自检。
- 浏览器：优先用本机已装的 **Chrome / Edge**；没有时再装 Playwright 的 Chromium。
- 语音识别模型（SenseVoice + 标点，约 **230 MB**）在第一次转写时自动下载。
- YouTube 单条等场景可能还需要 `yt-dlp`。

## 合规

只抓公开作品，用于个人学习研究。不转载、不二次分发原视频或文案、不商用。登录 cookie 只存在本机。一次只调研一个博主，不要并发狂跑。
