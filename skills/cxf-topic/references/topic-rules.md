# 出题规则

## 一条选题长什么样

- **题干**：一件可拍的事、一次冲突、一个具体做法或翻车，一句话说完。不要「如何成为…」空壳，不要已经写好的爆款标题。
- **依据**：S/O/M/P 编号，或「第②节方向1」「第⑤节主推」等可回溯位置。多条依据时写最硬的 1～3 个。
- **适合你**：一句，必须挂钩档案（他的经历、人群、产品或偏好），禁止只写「这个话题流量大」。

## 怎么从档案长出题

优先从这些组合长：

1. 故事 S + 方向 → 「把这件事讲给目标人群听」
2. 观点 O + 人群痛点 → 「用他的原话立场回应卡点」
3. 方法 M + 适用条件 → 「教一步他真用过的做法」
4. 产品犹豫点（第⑤节）→ 「正面回答买之前最常问的那句」
5. 翻车/转折故事 → 流量向共鸣（无产品时尤其有用）

同一条故事不要拆成两道几乎一样的题。5 条之间角度要分开（经历 / 观点 / 方法 / 产品 / 人群各有侧重更佳）。

## 排序

1. 先排除：禁区、讨厌、否掉过、与方向无关、只有推测没有事实的。
2. **有产品**：转化/引流（咨询、私信、了解产品、对比犹豫）排前；纯情绪流量排后。
3. **无产品**：共鸣、讨论、转发潜力排前；硬广式产品句不要硬造。
4. 具体 > 抽象；亲身经历 > 行业正确废话。

## 少于 5 条时

照实交。末尾写还差什么，例如：

- 「再补 1 个真实客户对话，转化题能更尖」
- 「再补 2 个你亲身经历的小故事，能出满 5」

不要用通用热点凑数。

## 换一批

用户说换一批：新题干与上一批明显不同；仍挂依据；仍最多 5 条。档案没变就不要假装有新调研。
