# 怎么读【我的档案】

出题前默读这些节。找不到某节就当空，不要臆造。

## 必看

| 节 | 用来干什么 |
|---|---|
| ② 想做的方向 | **底线抓手**。有大致方向即可出题；多个方向时优先「已确认」，否则用用户刚选定的，再否则反推一个并标明待改 |
| ③ 想讲给谁听 | 题干里的「对谁说」、痛点从哪来 |
| ④ 故事 / 观点 / 方法 | **主依据池**。优先带 `[事实]` `[原话]` 的 S、O；M 要有适用/失效/例子才稳 |
| ⑥ 不碰的话题、出镜方式 | 排除禁区；题干别要求他做不到的出镜形式 |
| ⑦ 选题偏好 | 喜欢加分，讨厌和否掉过的直接排除 |

## 选看

| 节 | 用来干什么 |
|---|---|
| ① 我是谁 | 补经历线索；类型（有产品/有经验没产品/还在找方向）影响排序 |
| ⑤ 产品与服务 | 有则优先转化/引流题；客户犹豫点、买完原话是好钩子 |
| ⑧ 使用须知、待确认 | 遵守须知；待确认清单不当主依据 |

## 标注怎么用

- `[原话]` `[事实]`：可以当主依据。
- `[推测]` `[待确认]`：最多当配角提示，不能当「他一定经历过」。
- 已删除的编号：当不存在。

## 找不到标准模板时

用户知识库可能是非模板笔记。仍按「方向 / 人群 / 经历或观点 / 产品 / 禁区」五类去抽；抽到的每条在依据里写清来源标题或小节名，没有 S/O 编号就写「档案·某某小节」。
