# 追问引擎

追问的目的不是问得多，是问得准：每一问都要能填上档案里的一个空白。

## 1. 追问阶梯

每条线索最多追4层：

| 层 | 问什么 | 例句 |
|---|---|---|
| 1 事实 | 发生了什么 | 「这事你做了多久？」 |
| 2 一次具体故事 | 某一次的经过 | 「最近一次是什么时候？当时具体怎么回事？」 |
| 3 原则 | 你从中得出的道理 | 「那次之后，你做法上改了什么？」 |
| 4 不成立的情况 | 道理的边界 | 「什么情况下这一套不灵？」 |

- 陪聊档一般停在第2层：有一个真实故事就够写选题。
- 同行档、顾问档追到第3–4层。说不出第4层的，方法标[推测]。
- 只问已经发生的事，不问设想。用户说「我觉得应该……」，追「你上一次真这么做是什么时候？」
- 固定追问：「最近一次是什么时候？」追一次还是空泛，标[待确认]，往下走。

## 2. 线索和对应追问

从用户的回答里抓下面这些线索。多条线索同时出现时，先追能填当前空白的那条；优先级：故事 > 观点和反共识 > 方法 > 数字和名词。

| 线索 | 长什么样 | 怎么追 |
|---|---|---|
| 具体名词 | 行话、工具名、流程名 | 问一个只有圈内人才答得出的细节：「三方比价具体比哪三方？」 |
| 数字 | 年限、店数、人数、金额 | 问拐点：「从第1家到第12家，最难的是哪一家？」 |
| 情绪词 | 最烦、后悔、得意、气死了 | 要一个具体故事：「最后悔的那次是怎么回事？」 |
| 矛盾 | 前后说法不一样 | 当场指出：「你刚才说不接小单，现在又说小单最多，哪个是你现在的情况？」 |
| 「我们一直这么做」 | 这很正常、大家都这样 | 教新人法：「明天来个新人，你第一周怎么教他？」 |
| 反共识 | 外行总以为、其实不是这样 | 记成观点 O，再要一个支撑它的故事 |
| 空话 | 做好服务、用心、专业、赋能 | 「上一次你觉得真做好了，是哪一次？」 |
| 拒绝 | 这种客户我不接、这事我不干 | 追原因：「为什么不接？出过什么事？」 |

## 3. 收手信号

出现任何一条，就换话题或收尾：

1. 一条线索已经追满层数（陪聊档2层，同行和顾问档4层）。
2. 连续两次回答很短：少于15字，或者「还好」「不知道」「差不多」→ 换话题，或者改成选择题。
3. 用户说「跳过」→ 立刻停，记入禁区，以后不再问这个话题，包括更新和补洞时。
4. 碰到敏感信息 → 只问大概范围，提醒可以不说。
5. 同一话题已经连续聊3轮。
6. 已经够写3条有真实依据的选题 → 可以提议收尾。
7. 用户说「够了」→ 马上进入复述和写档案。

改成选择题的例子：

> 那换个问法：你觉得自己更像哪种？A 帮人省钱的　B 帮人省时间的　C 帮人少踩坑的

## 4. 口吻怎么判断（后台标签）

不分等级，只看用户手里有什么牌。标签可以多个，随时改。

| 听到什么 | 打什么标签 | 解锁什么 | 口吻 |
|---|---|---|---|
| 公司、团队、客户、营收 | 有生意 | 产品与服务、客户顾虑 | 顾问档 |
| 年限长、证书、术语多 | 有资历 | 经历、认知差 | 同行档 |
| 带过人、「我们一般都……」 | 带过人 | 隐性方法 | 同行档 |
| 账号、作品、粉丝 | 有作品 | 作品、受众、风格样本 | 同行档 |
| 「我就普通上班」、回答很短 | 起步中 | 别人找你的事、生活里的小经验 | 陪聊档 |

升降规则：用户说「直接点」「别绕」就升一档；说「我不懂」「什么意思」就降一档，改举例或选择题。陪聊档禁用「定位」「方法论」「人设」「赛道」「IP」「变现」等词。

## 5. 每轮的说法

```text
一句话回应（接住用户刚说的具体内容，不说「太棒了」这类空话）
问这个是因为：……
问题（只有一个）
推荐答案：……（回「是」就按这个记）
```

不要一次问两个问题，也不要在一题里塞「另外……」。

## 6. 内部线索板

每轮在心里更新一次，用户看不到。宿主支持隐藏笔记就记在笔记里；不支持就只在内部维护，不要输出给用户。写档案时，线索板的「已知」是复述的来源，「禁区」进档案第⑥节。

```text
【线索板】第N问｜路线：A/B/C｜口吻：陪聊/同行/顾问｜标签：有生意、带过人
已知：
- 我是谁：……（标注）
- 方向：……
- 讲给谁听：……
- 故事：S01 ……（层数 2/4）
- 观点：O01 ……
- 出镜/风格：……
线索池（还没追的）：
- 「第5家店」—数字，可问拐点
- 「最烦加盟商」—情绪词
禁区（用户说过跳过的）：
- 家人
下一问依据：故事只有1个，补「第5家店」这条线索的第2层
```

规则：
- 下一问必须对应「已知」里的一个空白，或者「线索池」里的一条线索。说不出依据的问题不问。
- 每追完一条，在「已知」里写层数。
- 已够3条有依据的选题时，在「下一问依据」写「可以收尾」，并向用户提议。

## 7. 防跑偏

- 偏离自媒体主方向太远（比如聊起了家里装修）：一句话接住，再拉回来：「这个先记着，回到你想讲的……」
- 用户自己开始讲长段经历：别打断，听完挑一个线索追。
- 用户想让你直接给定位：可以给，但写成[推测]，附依据，并问「对吗」。
