# cxf-fetch：先锋抓取

版本：VERSION 1.0.0

这个 Skill 的用处：把对标博主公开作品的「数据 + 逐字稿」存进本地文件夹，之后再从里面提炼写作技巧。
**它不是固定流程**：先从用户的话里解析出参数，再调一次脚本。

说话要求：大白话，短句。不讲 MCP、API 这些词。对用户可见文案用「先锋抓取」，不要用 platform-scraper 当产品名。

## 一、先判断是哪种请求

| 用户给的东西 | 模式 | 做什么 |
|---|---|---|
| 一条**作品**链接或分享文案，没提「主页/博主/前N条」 | 单条 | 只抓这一条：数据 + 逐字稿，按需附评论 |
| **主页**链接，或作品链接加上「调研这个博主/作者」「他最火的几条」 | 博主 | 时间范围内按指标排序，取前 N 条：清单 + 每条逐字稿 |
| 本地视频/音频文件 | 文件 | 只做转写 |

用户给作品链接却要调研博主时，加 `--author`：脚本会先找到作者主页。

## 二、把用户的话翻译成参数

| 用户的说法 | 参数 | 缺省值 |
|---|---|---|
| 「近半年」「最近6个月」 | `--since 180d` | **180d（近半年）** |
| 「近3个月」「最近一季度」 | `--since 90d` | |
| 「近一个月」「这个月」 | `--since 30d` | |
| 「今年以来」 | `--since 2026-01-01`（YYYY-MM-DD，按当年填） | |
| 「从5月开始」 | `--since 2026-05-01` | |
| 「全部」「有史以来」「不限时间」 | `--since all` | |
| 「点赞最高」「最火」「爆款」 | `--sort likes` | **likes** |
| 「播放最高」「看的人最多」 | `--sort plays` | |
| 「收藏最多」「干货」 | `--sort collects` | |
| 「评论最多」「争议大」 | `--sort comments` | |
| 「转发最多」 | `--sort shares` | |
| 「前10条」「Top5」「三条」 | `--top 10/5/3` | **10** |
| 「带上评论」「看看评论区」 | `--with-comments 30`（可改条数） | 不带 |
| 「只要数据」「先看清单」 | 用 `list` 子命令或 `--no-transcript` | 转写 |
| 「存到 X 文件夹」 | `--out "X"` | `~/知识库/对标博主` |

规则：
- 能从话里推断的不要再问，按缺省值直接跑。只有**链接缺失**时才问一句「把博主主页或视频链接发我」。
- 平台不支持某个指标时脚本会自动换并提示，你转告用户即可：抖音拿不到别人的播放量，按「播放」会全为空；YouTube 主页列表没有点赞数，会改按播放排。
- 开跑前用一句话复述，例如「抖音·西门聪明蛋XD·近半年·按点赞·前10条·不带评论，开始了」，**不用等确认**。

## 三、安装（第一次用，Windows / Mac 都一样）

需要 Python 3.10+。在本 Skill 的 `scripts/` 目录里执行：

```bash
pip install -r requirements.txt          # httpx playwright sherpa-onnx numpy imageio-ffmpeg
python platform_top.py doctor            # 自检；缺什么会在 pip_install 字段里列出来
```

- 浏览器：脚本优先用电脑上已装的 Chrome / Edge 领取游客身份，都没有时运行 `python -m playwright install chromium`。
- 语音识别模型（SenseVoice + 标点，约 230 MB）在第一次转写时自动下载到 `~/.platform-scraper/models`。GitHub 下载慢时可设置环境变量 `GITHUB_PROXY`。
- YouTube 或其他网站的单条作品还需要 `pip install yt-dlp`。

## 四、命令

```bash
# 博主模式：清单 + 逐字稿（主页链接、分享文案都行）
python platform_top.py run "<主页链接>" --since 180d --sort likes --top 10 --out "<知识库目录>" [--with-comments 30]
# 单条模式：给作品链接时 run 会自动识别；也可以强制用 video
python platform_top.py video "<作品链接或分享文案>" --out "<知识库目录>" [--with-comments 30]
# 只出清单，先给用户挑
python platform_top.py list "<主页链接>" --since 90d --sort collects --top 10
# 给清单补逐字稿（已完成的自动跳过，可以断点续跑）
python platform_top.py transcribe "<知识库目录>/抖音_某某/works.json"
# 本地文件（视频号等抓不到时，让用户自己下载）
python platform_top.py file "D:/下载/xxx.mp4" --out "<知识库目录>"
# 抖音扫码登录（只在需要时用，见第六节）
python platform_top.py login
```

stdout 最后一行一定是 JSON，读它判断结果；过程日志输出在 stderr。

## 五、产出

```
<知识库目录>/<平台>_<博主昵称>/
  00_作品清单.md   # 排名、标题、发布日期、播放/点赞/评论/收藏/转发、链接；标出置顶和图文；覆盖不全时有 ⚠️
  works.json       # 同一份数据的机器可读版
  01_<标题>.md     # 元数据 + 简介 + 逐字稿 +（可选）热门评论
  ...
```

单条模式只写 `<平台>_<作者>/<标题>.md`。每份逐字稿都会写明「文字来源」：平台字幕或本地语音识别（机器识别，专有名词可能有错）。

跑完后给用户的回复：清单的前几行（标题 + 核心数据）、保存位置、失败或跳过了哪几条及原因。**不要编造没抓到的数字**。

产出可作为「对标素材」线索交给先锋资料库追加，但**不自动改【我的档案】**；用户确认后再交给 `cxf-library`。

## 六、什么时候必须停下来问用户（退出码）

| 退出码 | 含义 | 你怎么做 |
|---|---|---|
| 0 | 成功 | 汇报结果；如果 `coverage_note` 不为空，原样转告 |
| 2 | 缺依赖 | 按 `pip_install` 字段装好再重跑 |
| 3 | 被拦（要登录、验证码、风控、签名失效） | **立刻停止，不要重试超过一次，绝不尝试破解验证码**。把 `error` 告诉用户，给出选项：①稍后再试；②抖音运行 `login` 扫码登录；③用户自己导出 cookie 文件，通过 `--cookies` 传入 |
| 4 | 链接认不出，或平台不支持 | 按第七节走备选 |

抖音特别说明：不登录时，主页只能拿到**最新的约 35–45 条**（第二页起平台不给访客数据，2026-11-03 实测）。大多数博主近半年的作品都在这个范围内；如果更早的作品没扫到，清单里会出现 ⚠️ 提示。这时**先问用户**要不要扫码登录，别自作主张。`login` 会弹出一个浏览器窗口，用户用抖音 App 扫码，脚本只把登录 cookie 保存在用户自己电脑的 `~/.platform-scraper/`。

## 七、平台矩阵与备选方案

| 平台 | 主页 Top N | 单条 | 逐字稿 | 评论 | 备选 |
|---|---|---|---|---|---|
| 抖音 | ✅ 游客（最新约40条），登录后可翻页（未验证） | ✅ | 下载 + 本地识别 | ✅ 游客可取 | 被拦时用 `login`，或用 TikTokDownloader 的图形界面 |
| B站 | ✅ 游客 + WBI 签名；偶尔触发 -352/412 风控 | ✅ | 下载 + 本地识别（未验证） | ✅ 游客只拿到热评前几条 | 等几分钟再试 |
| YouTube | ✅ yt-dlp（按播放排序，日期为近似值） | ✅（未验证） | 优先平台字幕，没有就识别（未验证） | ❌ | — |
| 小红书 | ❌ 主页需要登录 | 未验证（yt-dlp 单条笔记） | — | — | 装 xiaohongshu-mcp（扫码登录，有用户主页工具），或 MediaCrawler（扫码，非商用协议）；把视频文件交给 `file` |
| 视频号 | ❌ | ❌ | — | — | 用户在电脑版微信里自己下载或录屏，然后用 `file` 转写 |

可选增强（不是必需）：画面里有硬字幕时可以 OCR 校对；也可以让大模型给逐字稿纠正错别字和专有名词，但要保留原稿。

## 八、合规与礼貌

- 只抓**公开**作品，用于**个人学习研究**。不转载、不二次分发原视频或文案、不商用。
- 不批量抓陌生人的个人信息。评论只保留昵称、内容和点赞数。
- 一次只调研一个博主。脚本自带 1–3 秒间隔，不要并发狂跑。
- 登录 cookie 只存在用户本机，不要发给任何人或上传。
- 抖音签名代码来自 Evil0ctal/Douyin_TikTok_Download_API（Apache-2.0），见 `scripts/dysign/`。

- 抖音主页：游客身份、`--since 90d` 过滤、按点赞排序、生成清单

- B站：主页按 `--since 180d` 出清单；单条视频的元数据和热评
- YouTube：主页 `--since 90d` 出清单

未验证：

- B站视频下载和转写
- YouTube 字幕和转写、单条
- 小红书单条
- 全新环境里一键安装和自动下载模型
- **Windows / Mac 实机运行**
- 平台接口随时可能改版，失效时看第六节
